## 생성자 함수 호출
생성자 함수 내부의 this에는 생성자 함수가 생성"할" 인스턴스가 바인딩된다.
```
//생성자 함수
function Circle(radius){
    this.radius = radius;
    this.getDiameter = function () {
        return 2 * this.radius;
    }
}

//반지름이 5인 circle 객체 생성
const circle1 = new Circle(5);
const circle2 = new Circle(10);

console.log(circle1.getDiameter()); //10;
console.log(circle2.getDiameter()); //20;
```
생성자 함수 = 객체를 생성하는 함수 <br>
일반 함수와 동일하게 생성자 함수를 정의하고 new 연산자와 함께 호출하면 생성자 함수로 동작<br>
new연산자와 함께 생성자 함수를 호출하지 않으면 __일반 함수__ 로 동작

```
// 일반 함수 호출
const circle3 = Circle(15);
console.log(circle3); //undefined

console.log(radius); //15
```

## function.prototype.apply/call/bind 메서드에 의한 간접 호출
apply / call / bind 메서드는 function.prototype의 메서드이다.<br>
(모든 함수가 해당 메서드를 상속받아 쓸 수 있다.) <br>

apply / call 메서드는 this로 사용할 객체와 인수 리스트를 인수로 전달 받아 함수를 호출

```
@param thisArg - this로 사용할 객체
@param argsArray - 함수에게 전달할 인수 리스트의 배열 또는 유사 배열 객체
@returns 호출된 함수의 반환값
Function.prototype.apply(thisArg[,argsArray])

@param thisArg - this로 사용할 객체
@param arg1, arg2, ... - 함수에게 전달할 인수 리스트
@returns 호출된 함수의 반환값
Function.prototype.call (thisArg[,arg1[,arg2[, ...]]])
```

예제
```
function getThisBinding(){
    return this;
}

//this로 사용할 객체
const thisArg = {a:1};

console.log(getThisBinding()); //window

console.log(getThisBinding.apply(thisArg)); // {a:1}
console.log(getThisBinding.call(thisArg)); // {a:1}

```
apply  / call 메서드는 함수를 호출하면 첫 번째 인수로 전달한 특정 객체를 호출한 함수의 this에 바인딩 <br>
즉, 이 두가지 메서드의 차이점은 __호출할 함수에 인수를 전달하는 방식__ 이 다를뿐 동일하게 동작 <br>

__인수를 전달하는 예제__
```
function getThisBinding(){
    console.log(arguments);
    return this;
}

//this로 사용할 객체
const thisArg = {a:1};

//apply 메서드
console.log(getThisBinding.apply(thisArg,[1,2,3]));
// Arguments(3) [1, 2, 3, callee: f, Symbol(Symbol.iterator)： f]
// {a:1}

//call 메서드
console.log(getThisBinding.call(thisArg,1,2,3));
//Arguments(3) [1, 2, 3, callee: f, Symbol(Symbol.iterator)： f]
//{a:1}
```

Function.prototype.bind 메서드는 __this로 사용할 객체__ 만 전달 
```
function getThisBinding() {
    return this;
}

const thisArg = {a:1};

console.log(getThisBinding.bind(thisArg)); //getThisBinding
console.log(getThisBinding.bind(thisArg)()); //{a:1}
```
__bind 메서드__ <br>
this와 메서드 내부의 중첩 함수 혹은 콜백 함수의 this가 불일치 하는 문제 해결하기 위해 사용됨

```
const person = {
    name : 'Lee',
    foo(callback){
        setTimeout(callback,100);
    }
};

person.foo(function() {
    console.log('hi name is ${this.name}'); // hi name is.
    //일반 함수로 호출된 콜백 내부의 this.name은 브라우저 환경의 window.name과 같음
    //window.name은 브라우저 창의 이름을 나타내는 빌트인 프로퍼티이고 기본값은 ''이다.
    //node.js에서는 undefined이다.
})
```
person.foo의 callback 함수가 호출되기 이전 시점에서 this는 foo메서드를 호출한 객체(person객체)를 가리킴 <br>
그러나, callback함수가 일반 함수로 호출된 시점에서 this는 전역객체를 가리킴<br>


이때 person.foo의 callback함수는 외부함수를 돕는 헬퍼함수 역할을 함<br>
즉, person.foo 내부의 this와 콜백함수 내부의 this가 다르면 문맥상 문제가 발생함<br>
__이럴 때 쓰는것이 bind 메서드__

```
const person = {
    name : 'lee',
    foo(callback){
        setTimeout(callback.bind(this),100);
    }
};

person.foo(function(){
    console.log('hi name is ${this.name}.'); //hi name is Lee
})
```
